## Deploy
This is a static website. Connect this repository to Cloudflare Pages, GitHub Pages, Netlify or Vercel.

For Cloudflare Pages, select **None** as the framework preset, leave the build command blank, and set the build output directory to `/`.

The homepage is `index.html`.
